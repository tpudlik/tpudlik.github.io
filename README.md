# tpudlik.com

Source for [www.tpudlik.com](https://www.tpudlik.com/), Ted Pudlik's personal
website, built with [Jekyll](https://jekyllrb.com/) and served by GitHub Pages.

## Building locally

```sh
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000/>.
